## Somewhat done

The engine is still in the early stages of development. But it's working much better than before with type safety.

There are plenty of utilities that doesn't bloat the core game engine by separating extensions, plugins and core engine.

I've been experimenting in some procedural animation and optimizations along with asset importing like BSP file formats and glTF conformance.

The renderer has no legacy handles. Vulkan has gone a long way.
